About the project

A portfolio shaped like Ubuntu 20.04: the dock down the left, draggable windows, the dark-orange palette and the GNOME behaviours that go with them.

What it demonstrates

  • Applications defined in one config
  • A GNOME dock and window behaviour
  • Static export
  • A contact form without a backend
  • A working calculator

Stack

  • Next.js
  • React
  • Tailwind CSS
  • EmailJS
