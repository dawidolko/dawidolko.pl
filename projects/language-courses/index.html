About the project

Language Courses is a course enrolment platform. Visitors browse the catalogue, open a course to see its lessons and teacher, and add it to a basket with the date they want. Checking out turns the basket into enrolments — real rows against the user, each with a lesson date and a status — rather than an order that somebody has to type into a system afterwards.

What it demonstrates

  • A basket that produces enrolments
  • A date chosen at the point of buying
  • Roles enforced by middleware
  • An admin area that covers the whole model
  • Accounts with a profile

Stack

  • Laravel
  • PHP
  • MySQL
  • Blade
  • Docker
