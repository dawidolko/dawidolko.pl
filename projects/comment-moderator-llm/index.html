Comment Moderator LLM

Nov 2026

Forum comment moderation with a local LLM and RAG over the forum rules

Source code (opens in a new tab)

About the project

A Python application that moderates forum comments with a local LLM served by Ollama. Every comment gets categories, a severity, a decision and a one-sentence reason; memes and screenshots are read by a vision model first, whole files are moderated in one run with a text report and an SVG chart, a chat answers questions about a file, and the RAG mode cites the paragraph of the forum rules the decision rests on. A Gradio web app and a Typer CLI share one core, and Docker Compose starts Ollama, the models and the app.

What it demonstrates

  • Verdicts constrained by a JSON schema
  • Memes read by a vision model
  • Batch moderation with TXT and SVG reports
  • Chat about a file
  • RAG that cites the forum rules
