About the project

Frontend Skills is a free, open-source set of skills for AI coding agents that write front-end code. One command, npx github:dawidolko/frontend-skills init, learns the project's stack and its own conventions, then installs only the skills that fit, in the format each agent reads: 17 agents are supported, among them Claude Code, Codex, Cursor, Copilot and Gemini CLI. The audit command checks HTML, CSS, JavaScript and framework templates against 275 rules, each with a stable id, a severity and a public source such as WCAG, MDN or web.dev, and reports the file, the line, why it matters and the fix, with an exit code for CI. explain shows one rule in full. The command is a Node.js CLI with no runtime dependencies, the dictionary holds 50 skills, and 1087 tests check it. The site at skills.dawidolko.pl is in English and Polish.

What it demonstrates
