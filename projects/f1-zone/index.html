F1 Zone

A poster shop without a framework

Live site (opens in a new tab) Source code (opens in a new tab)

About the project

F1 Zone sells Formula 1 posters: tracks, cars and drivers. The catalogue lives in a JavaScript data file, a modal opens any poster full size, and the cart keeps its contents in localStorage, so closing the tab does not empty it.

What it demonstrates

  • A cart that survives the tab
  • Duplicate protection with feedback
  • The catalogue is data
  • A product modal built by hand
  • Live totals in the navigation

Stack

  • HTML5
  • Sass
  • JavaScript
  • WebP
