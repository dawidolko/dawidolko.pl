About the project

Skribly is a private project I build with four friends. It is a family of developer tools for people who write software with AI coding agents, and it is non-commercial: nothing is sold, it has no clients and offers no services. Skribly Agent is a desktop app for macOS, Windows and Linux that runs AI coding agents side by side and shows which one is working, which waits for a decision and which has finished; it is in development and its installers are not public yet. agent-skills gives seven coding agents 38 portable skills for tests, reviews, audits and clean commits that adapt to each project through a project profile. Skribly Tracker is the issue tracker of the family, built on Node.js, TypeScript and PostgreSQL, with Kanban boards and a REST API of 53 operations checked by contract tests; it is in development and not deployed. Skribly Core holds the shared contracts and the server kit the apps are built on, Skribly UI is the design system, built to WCAG 2.2 AA as a target and shown at ui.skribly.pl, and Skribly Docs explains all of it at docs.skribly.pl in English and Polish. Being added, and not public yet: one sign-in for the apps (Skribly ID), one address for their APIs (Skribly API), a local console of the repositories (Skribly Hub), a few small sites and the templates new apps and sites start from. Co-created with Piotr Smoła, Michał Pilecki, Konrad Pluta and Mateusz Olko; the repositories stay private while we build.

What it demonstrates

  • Agents you can watch while they work
