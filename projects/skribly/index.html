About the project

Skribly is an ecosystem of tools for people who build software with AI coding agents. Skribly Tracker holds the tasks and serves them through a REST API, Skribly Agent is a desktop app that starts AI coding agents on those tasks and shows what each one is doing, and agent-skills gives every agent 29 portable skills for testing, reviewing and committing that adapt to each project through a project profile and confirmed lessons. Underneath, Skribly Core holds the shared contracts for identity, CloudEvents events, the app registry and webhooks, and Skribly UI is the design system on React Aria with tokens and plain CSS, published at ui.skribly.pl. Everything is documented at docs.skribly.pl. Co-created with Piotr Smoła, Michał Pilecki, Konrad Pluta and Mateusz Olko as a non-commercial project.

What it demonstrates

  • Task tracking people and agents can share
  • Agents you can watch while they work
  • Skills that adapt to each project
  • Shared contracts and one design system
  • You read every change before it goes in
  • Work stays on your own computer and server
